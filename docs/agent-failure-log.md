## 2026-09-26 单查/批量分发导致汇率语义分裂
- 现象：`CNY HKD` 单查输出"暂不支持"，`CNY HKD EUR` 批量查却给出经 USD 合成的 `1 CNY = 1.10262 HKD`，同一对币种两种答案
- 原因：002 为了算出 CSV 里没有的 `USD → EUR`，把一跳中转只写进 `quote_multi`；main 按目标数量把单查分给仅直达的 `quote_pair`，两条路径语义不一致。任务简报也没写清"无直达时是否允许中转、单查是否同一规则"
- 对策：所有查询走同一套 `resolve_rate`；中转必须标注"经XX中转估算，不一定为真实汇率"；用单查与批量输出对比的测试防复发。给 Agent 的指令里，若允许合成汇率，必须写明单查/批量共用同一规则，并规定中转时的输出格式
