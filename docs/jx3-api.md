# 剑网3 数据资源：JX3API

> 记录时间：2026-09-22 · 来源：玩家社区第三方 API（非官方）
> 官网：https://www.jx3api.com

## 这是什么

剑网3 社区维护的数据接口站，覆盖游戏内各类数据查询。口号"快意江湖，数据先行"。

## 鉴权方式（重要）

- 需要注册获取 **token**（站点访问令牌，部分接口要求 LV.1 及以上）
- 部分接口还需 **ticket**（推栏标识鉴权）
- 示例：`GET/POST https://www.jx3api.com/arena/schools?mode=33`
  - `mode`：比赛模式（默认 33，即 3v3 名剑大会）
- ⚠️ 第三方服务，稳定性/限流无保障，项目里必须做好异常处理与降级

## 与本计划相关的接口类目

| 类目 | 用途 |
|---|---|
| 名剑相关（排行 / 战绩 / 统计） | 竞技场门派胜率、登场率——旗舰项目的数据佐证 |
| 心法配装 | 配装数据，RAG 知识库素材 |
| 奇遇相关（汇总 / 攻略 / 统计） | RAG 知识库素材 |
| 角色查询 / 名片 / 信息 | 可能的扩展功能 |
| 物价交易 / 聊天记录 / 骗子查询 | 备用灵感 |

## 在项目计划中的位置

- **W3 项目 1（技改情报聚合器）**：主数据源仍是官网公告抓取；可选扩展——接入名剑统计做"技改前后门派数据对比"推送
- **W6 旗舰项目（技改解读助手）**：RAG（技改文本）+ 名剑统计数据交叉验证，回答"技改对某门派竞技场的影响"
