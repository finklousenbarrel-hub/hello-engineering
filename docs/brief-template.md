# 任务简报模板 v1

## 模板本体
# 简报 NNN：标题
## 目标（做什么+不做什么）
## 环境（项目现状，每句话必须是当下真实的）
## 限制（含命名清单：本任务新引入的目录/文件名，逐一列出）
## 验收标准（正向条款 + 至少一条反向条款如"无丢失/无改动"）

## 质量检查清单（发出前自查）
- [ ] 每个新名词拼写正确，能让执行者复述
- [ ] 限制栏与验收栏无矛盾
- [ ] 环境栏无过期信息
- [ ] 无占位词
- [ ] 验收标准每条都可独立验证
